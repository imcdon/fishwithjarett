# Fish with Jarett

Guided salmon and trout on Lake Michigan tributaries (Wisconsin, Indiana, Michigan).

Public site source for fishwithjarett.com. Staging preview is hosted under Webstar Client Portal (Path A).

## Local

Serve the folder with PHP/Apache (e.g. XAMPP). Staging HTTP auth is active on localhost and Webstar hosts; it turns off on fishwithjarett.com.

## Security

No plaintext passwords in this repo. See Webstar `clients/SECURITY-CHECKLIST.md` for the Path A workflow.
